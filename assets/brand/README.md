# a0-plugin-glitchtip brand assets

PROPOSAL: the owner signs off logos. Nothing here is final.

Part of the Patchbay family (see `DESIGN.md`). All files are hand-written SVG,
generated by `family-build.py`; no raster sources, no stock icons, no AI imagery.

## Construction (family-wide)

- 64 x 64 grid.
- Frame: rounded square, outer edge 4..60 (56 x 56), outer corner radius 8,
  6-unit stroke, no fill.
- Pin: 14 x 14 filled block in the signal colour in the bottom-right corner
  (x 46..60, y 46..60), continuing the frame's outer radius.
- Glyph box: 28 x 28 at 16..44, 4-unit strokes, butt caps, mitre joins,
  straight segments only.
- At 16 px the frame is 1.5 px and the glyph stroke 1 px.

## This plugin's glyph

An error pulse with one spike: flat baseline, one sharp peak and trough, back
to baseline (`M19 35H25L29 22L34 40L37 31H41`). It stands for event capture:
a single abnormal beat in the agent loop becoming one recorded event.

## Files

`logo.svg`, `logo-dark.svg`, `wordmark.svg`, `wordmark-dark.svg`,
`social-card.svg`, `social-card-dark.svg`, PNG previews of each,
`family-sheet.png` (all five plugins at 16, 32, 128 px).

## Rebuild

```bash
python3 assets/brand/family-build.py glitchtip assets/brand
# then render and optimise, e.g.
resvg assets/brand/logo.svg assets/brand/logo.png
oxipng -o 4 assets/brand/*.png
```

The build script emits wordmark text as `<text>` and outlines it with
inkscape afterwards.
